# Trip Planner

A tiny trip budget planner: dates, stops, expenses in PKR, and a USD estimate.

**Live:** https://mashhoodr.github.io/trip-planner/

It's the demo app for *Building Software Factories with Antigravity* (Pehla Qadam Apps Bootcamp, Lahore, 20 Oct 2026). During the talk, an agent loop picks up issues filed here, fixes them and ships the fix.

## Found a problem?
[Open an issue](https://github.com/mashhoodr/trip-planner/issues/new/choose). Include the user id shown at the bottom of the app (e.g. `u-4821`) so it can be reproduced.

## Run it
```bash
npm test     # unit tests (Node 20+)
npm start    # http://localhost:4173
```

Agents: start with [AGENTS.md](AGENTS.md).
